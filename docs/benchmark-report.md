## Benchmark setup

- NVIDIA GeForce GTX 1650 (4 GiB), `performance` profile, CUDA, offline replay. Each run processed 300 frames. The first 10 frames were excluded from latency statistics.
- YOLOX-Nano with evaluation confidence threshold 0.3. TANet used `scale=0.25` in B and when the policy selected enhancement in D.
- The report uses measurements from multiple sessions. Mode A and the ten mode D runs that bypassed enhancement use previously collected measurements.
